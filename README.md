# DTS - DIRECT. THE. SHOT

Professional sports photography and media coverage website for DTS (DIRECT. THE. SHOT) based in Abu Dhabi, UAE.

## 🚀 Features

- **Responsive Design** - Mobile-first approach works on all devices
- **Modern UI** - Clean, professional aesthetic with gradient accents
- **Portfolio Gallery** - Instagram reel-style carousel showcase
- **Package Pricing** - Multiple service tiers with clear pricing
- **Image Error Handling** - Graceful fallbacks for missing images
- **Accessibility** - Semantic HTML and proper ARIA labels
- **Performance Optimized** - Fast loading with smooth animations

## 🚀 Deployment

### GitHub Pages
1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Choose `main` branch as source
4. Website will be live at `https://dts-photography.github.io`
